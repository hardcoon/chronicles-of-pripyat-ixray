# Универсальный QA-лог точек

Developer-only инструмент для быстрого сбора точек будущих спавнов и других
пространственных задач. Предмет `pf_qa_point_logger_tool` автоматически
выдаётся только при `pf_stash_qa.is_developer_mode() == true`. Пока Developer
mode активен, модуль периодически сверяет инвентарь и восстанавливает предмет
после подготовки стартового набора или F9 без дублей.

Первое использование после загрузки игры создаёт новый файл
`$logs$\pf_qa_points_YYYYMMDD_HHMMSS.log`. Повторные использования добавляют
TSV-строки с координатами, углами камеры и актёра, векторами направления,
позицией камеры, level/game vertex и временными метками.

Доступны двойной клик, быстрый слот и контекстное действие. В обычном режиме
запись блокируется fail-closed, а случайно сохранённая копия предмета адресно
удаляется после загрузки.
