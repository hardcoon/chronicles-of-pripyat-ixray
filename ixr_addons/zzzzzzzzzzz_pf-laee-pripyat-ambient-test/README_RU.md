# Тест 5: эмбиенты Припяти из LAEE

Это изолированный тестовый слой для Chronicles of Pripyat 4.26 IX-Ray.
Он заменяет только звуковые каналы наружного эмбиента большой Припяти.
Погода, музыка, частицы, скрипты и остальные ресурсы Lost Alpha Enhanced
Edition не переносятся.

Источник — установленный read-only донор `Lost Alpha Enhanced Edition`.
Из его финального `env_ambient.ltx` перенесены отдельные наборы `night`,
`morning`, `day`, `evening`, `rain`, `thunder`, `tuman` и `tuman_night`.
Они сопоставлены штатным секциям `pripyat_full.ltx`, включая дополнительные
имена `dark`, `fog` и `th`, которые использует Paradox Weather Unit.

Семь навязчивых сэмплов `rnd_fly*` и `rnd_flies*` намеренно исключены: игрок
уже отверг близкие звуки мух и насекомых в предыдущем IWP-тесте. Все остальные
выбранные OGG копируются побайтно под приватный путь `pf_laee_ambient`, поэтому
они не перекрывают одноимённые ресурсы базовой игры или других аддонов.

Сборка воспроизводится скриптом `tools\build_selected_laee_ambient.ps1`.
Скрипт принимает явные пути к распакованному `env_ambient.ltx`, базовому корню
звуков LAEE и необязательному корню звуков финального патча. Тяжёлая распаковка
должна находиться только в `C:\GPT_Project\Stalker\.ixray-local\workspace`.
