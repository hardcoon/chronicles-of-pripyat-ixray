# Хранилище пользовательских данных IRC-чата

## Обязательное правило для релиза

Код аддона должен получать каталог пользовательских файлов только через
движковый псевдоним `$app_data_root$`. Нельзя записывать в код, конфигурацию или
скрипт абсолютный путь `C:\GPT_Project\Stalker\.ixray-local\runtime` и нельзя
вычислять его относительно каталога проекта.

Фактические пути различаются намеренно:

- разработка (`fsgame.dev.ltx`):
  `C:\GPT_Project\Stalker\.ixray-local\runtime\pf_irc_chat`;
- релиз (`fsgame.ltx`): `<папка игры>\userdata\pf_irc_chat`.

Поэтому при сборке и переносе аддона менять путь в Lua не требуется. Нужно лишь
сохранить вызов `getFS():update_path("$app_data_root$", "")` и штатный релизный
`fsgame.ltx`. Профили, локальная идентичность, mute-лист и история переписки
должны оставаться в этом пользовательском каталоге, а не внутри `ixr_addons`.

История хранится в `history.txt`. Это локальный UTF-8-файл с версией формата;
пароли NickServ, ключ комнаты и иные секреты в него не записываются.
