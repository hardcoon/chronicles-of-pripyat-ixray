# Маршруты отрядов

На `pripyat_full` обычные отряды `sim_default_*` фракций `zombied`,
`monolith` и `killer` перемещаются к своей штатной цели по небольшому
game graph, как в псевдо-алайфе. Население, принадлежность отрядов и
назначение целей задаются существующей симуляцией.

Аддон заменяет действие `reach_task` во вложенном планировщике ALife.
Штатный планировщик сохраняет приоритет боя, опасности и аномалий.
Другие фракции, сюжетные NPC и население `pf_pa_*` используют свои действия.
Подключение: DLTX `mod_script_pf_squad_nav.ltx`, без копии штатного `xr_reach_task`.

Используется проверенный граф из активного `all.spawn` и cross table,
с проверкой GUID и соответствия `level.ai`. Большая AI-сетка в Lua
не загружается. Маршруты кэшируются, команды выдаются не чаще двух
за 250 мс. Прямой участок ограничен 25 м; для обхода препятствия
используется путь к следующему соседнему узлу game graph.
Одинаковое назначение не пересоздаёт путь. При отсутствии движения
3 секунды действие останавливается и делает следующую попытку через 5 секунд.

Для устранения просадки при реакции NPC на опасность требуется также
исправление `ILevelGraph::Search` в `xrAbstractions.dll`: согласованная
эвристика A*, обработка узла один раз и кэш неудачного поиска на секунду.
Изменение ограничений прохода, начала, цели или бюджета поиска сразу
отменяет использование этого кэша. Исправление действует и на NPC
псевдо-алайфа, когда они передают управление штатному боевому AI.

Аддон не добавляет сохранённых полей и работает после загрузки существующего
сохранения. Для применения DLL необходимо полностью перезапустить игру.
