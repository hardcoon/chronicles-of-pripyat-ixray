# PDA Hacking для «Хроник Припяти 4.26»

Локальный порт PDA Hacking v1.23 на Call of Pripyat / IX-Ray. Аддон блокирует
прямое чтение четырёх PDA с координатами тайников и открывает отдельную
мини-игру при наличии USB с хакерским ПО.

USB уникальны для сохранения: фиолетовый тайник может выдать USB-1,
оранжевый — до USB-2, красный — до USB-3. Модуль перепрошивки поддерживает
КПК новичка, сталкера, ветерана и мастера, но по ПКМ показывает только ранги
реально имеющихся у актёра заблокированных КПК. Обычные рабочие КПК пунктов
перепрошивки не создают. Выбранное действие сразу выдаёт координаты через
обычную логику тайников и расходует ровно один модуль и один заблокированный
КПК, без повторной мини-игры. Удалять аддон перед загрузкой сохранения с его
USB или заблокированными PDA нельзя.

Основной интерфейс мини-игры оформлен как консоль восстановления PF-Linux:
компактные payload и команды расположены сверху, увеличенный построчный
`journalctl` — снизу, подсказки вынесены в `[?]`. Каждая команда постоянно
показывает собственный `[RUN]` и выполняется одним кликом без предварительного
выделения. Группы, границы, выбор и шкалы оформлены символами `#`, `+`, `-`,
`|` и `>`; штатные GUI-скролбары визуально закрыты, прокрутка работает колесом.

`ui_pf_pda_hacking_frame.dds` является отдельной копией штатного
`ui_actor_pda.dds`: металлическая рамка сохранена, а экранная полость заменена
ровным `#0d0f0f` без фонового изображения и шума. RUN, справка и закрытие
остаются текстовыми кликабельными областями на прозрачных DDS-состояниях.
Ресурсы воспроизводимо собираются
скриптом `tools/build_pf_pda_recovery_texture.py` без генеративной графики.

Исходный аддон распространяется по проприетарной лицензии. Публикация этого
порта требует отдельного разрешения автора Utjan.
