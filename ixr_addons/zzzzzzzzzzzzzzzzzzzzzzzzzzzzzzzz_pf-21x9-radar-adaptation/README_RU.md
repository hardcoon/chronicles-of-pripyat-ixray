# Адаптация радара под 21:9

Аддон переопределяет только `configs/ui/zone_map_21.xml`.

- Центр радара сдвинут вниз (`y="0.143"`), чтобы круг радара и компас не выходили в отрицательную экранную область на разрешениях 21:9.
- Размер окна компаса увеличен с `192 x 192` до `210 x 210`. У исходной текстуры `compass.dds` имеются прозрачные поля, поэтому её видимая рамка была меньше области мини-карты.
- Варианты интерфейса для 4:3 и 16:9 не затрагиваются.

Аддон использует текстуры из `zz_ixray-stalker2-hud` и должен загружаться после него.
