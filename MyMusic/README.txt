МОЯ МУЗЫКА
Поместите MP3 прямо в эту папку и полностью перезапустите игру.
В размещённом радио выберите третью вкладку «Моя музыка».
Имена файлов могут быть на русском.

MY MUSIC
Place MP3 files directly in this folder and fully restart the game.
On a placed radio, select the third tab, “My music”.
File names may contain Russian characters.
