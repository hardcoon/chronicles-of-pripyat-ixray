# Аддоны Chronicles of Pripyat

Лаунчер 1.5.1 получает список доступных аддонов из `index.json`. Только записи
этого каталога отображаются в разделе «Аддоны»; существующие `ixr_addons`
автоматически в каталог не добавляются.

Архивы хранятся отдельно от игровых патчей, в Release с тегом
[`chronicles_addon`](https://github.com/hardcoon/chronicles-of-pripyat-ixray/releases/tag/chronicles_addon).
Настройка источника загрузки в лаунчере применяется также к каталогу аддонов.
Для зеркала используется отдельный Release с таким же тегом, не игровой канал.

## Доступные аддоны

- **Зима 1.45** — необязательный зимний аддон с отдельной установкой.

Полная загрузка — 3,30 ГБ. Лаунчер собирает пакет из частей, проверяет его
и устанавливает в `ixr_addons/~winter` выбранной игры.

Сам каталог `chronicles_addon` не включается в игровые full/delta/initial-пакеты.
Архив аддона скачивается отдельно, только после его выбора пользователем.

Установка начинается после выбора галочки. Снятие галочки сохраняет файлы
и переименовывает `addon.init` в `addon.init_off`. Выбранные аддоны проверяются
на обновления при запуске лаунчера.

При первой установке загружается полный пакет. При обновлении лаунчер 1.5.1
скачивает только изменённые или отсутствующие файлы, а не весь архив заново.
Прерванная загрузка продолжается с уже полученных данных. Неперечисленные
пользовательские файлы сохраняются.
