# Chronicles of Pripyat 4.26 — IX-Ray

## О проекте

**Chronicles of Pripyat** — геймплейно-нарративный проект на движке
IX-Ray. Главный герой — Неизвестный, который не помнит своего прошлого и
приходит в Припять — туда, где когда-то его потерял.

Линейного сюжета нет: основой остаются свободное исследование и выживание.
Записки рассказывают о жителях Припяти и о том, что было скрыто за железным занависом. 
В их основе лежит информация из официальных источников, адаптированная
для игрового формата.

Цель проекта — показать более реальную и забытую сторону Зоны. Развивая идею
автора карты «Большая Припять», проект превращает город из декорации в большое
пространство для долгой игры, исследования и собственных открытий.

## Основные особенности

- свободное исследование Припяти без обязательной линейной истории;
- записки о жителях города и их судьбах после аварии;
- тайники, трансопрт, КПК и другие механики, дополняющие исследование;
- выживание, торговля, аномалии, артефакты;
- собственные игровые, интерфейсные и системные доработки IX-Ray.

## Установка

1. Скачайте [ChroniclesLauncher.exe](https://github.com/hardcoon/chronicles-of-pripyat-ixray/releases/download/dev-2026.08.26.1/ChroniclesLauncher.exe?v=20260827.1).
2. Запустите его из папки «Загрузки» или другой доступной для записи папки.
3. При необходимости выберите диск кнопкой с папкой, затем нажмите
   **УСТАНОВИТЬ ИГРУ**. Лаунчер создаст отдельную папку
   `Chronicles of Pripyat 4.26 IX-Ray`.

После установки лаунчер копируется в папку игры как `ChroniclesLauncher.exe`
и создаёт ярлык **Chronicles of Pripyat** на рабочем столе. Кнопка **ИГРАТЬ**
запускает локальную игру без подключения к интернету. Проверка обновлений
выполняется только по явному нажатию кнопки обновления.

Полная пользовательская сборка распространяется пакетами через GitHub
Releases. В репозитории находятся только README и игровые файлы, которые
относятся к авторским изменениям проекта. Внутренние инструменты, исходники
лаунчера, рабочая документация, резервные копии и локальные файлы разработчика
не публикуются.
