# Chronicles of Pripyat 4.26 — IX-Ray

Публичный репозиторий проекта Chronicles of Pripyat для IX-Ray.

## Установка

1. Скачайте `ChroniclesLauncher.exe` из раздела
   [Releases](https://github.com/hardcoon/chronicles-of-pripyat-ixray/releases).
2. Поместите лаунчер в отдельную папку, в которую должна быть установлена игра.
3. Запустите лаунчер и нажмите **УСТАНОВИТЬ ИГРУ**.

GitHub-аккаунт и token не требуются. После установки кнопка **ИГРАТЬ** запускает
локальную игру без подключения к интернету. Проверка обновлений выполняется
только по явному нажатию кнопки обновления.

Полная пользовательская сборка распространяется пакетами через GitHub
Releases. В репозитории находятся только README и игровые файлы, которые
относятся к авторским изменениям проекта. Внутренние инструменты, исходники
лаунчера, рабочая документация, резервные копии и локальные файлы разработчика
не публикуются.
